# Benchmark datasets

Contents of this directory are gitignored. Two kinds:

- `syn_scale/` — synthetic module-structured genomes for
  `grafting_scale_bench`, generated by `make_syn_scale_data.py`
  (deterministic seed). Regenerate with:

      python3 data/make_syn_scale_data.py -o data/syn_scale
      ./grafting_scale_bench data/syn_scale/taxmap.txt data/syn_scale/names.txt \
          data/syn_scale/genomes.list -p 8 -c results.csv

  The generator builds a DOMxPHYx...xSPECIES hierarchy with per-genome
  random backgrounds plus shared species/genus/family blocks and a rogue
  cross-species module per order, so observed k-mer classes are exact clade
  or rogue sets. Depth-6 nodes are genera (matching the bench's stage-D
  scan).

- A GTDB-scale real dataset can be dropped in the same layout
  (`taxmap.txt` child|parent rows, `names.txt` seqid\ttaxid rows,
  `genomes.list` of fasta paths); see doc/bonsai-gtdb-benchmark.md.
